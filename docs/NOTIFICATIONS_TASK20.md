# Task-20: Bildirim Sistemi (Toast + Inbox + Event Feed)

## Tamamlananlar

- `user_notifications` ile inbox sistemi eklendi.
- `event_feed` ile global/ülke bazlı olay akışı eklendi.

- Dashboard'da bildirim merkezi (Inbox + Event Feed) eklendi.
- Önemli aksiyonlarda sistemin inbox/event feed kayıtları üretilir hale getirildi.
