NoaSoft QR Menu API

JSON tabanlı token yapısı ile QR kod üretimini otomatikleştirin. Her başarılı istek aktif paketinizin limit ve sürelerinden düşer.

Kimlik Doğrulama

Admin veya müşteri panelinde oluşturduğunuz tokenı Authorization: Bearer <TOKEN> başlığı ile, JSON gövdesinde token alanında veya GET isteklerinde ?token=<TOKEN> parametresi ile gönderin.

Endpoint

https://qrmenu.noasoft.org/api/v1/qr

POST isteğinde JSON gövdesi, GET isteğinde sorgu parametreleri kullanılır. Doğrudan görüntü yerleştirmek için output=image veya embed=1 parametresini ekleyebilirsiniz.

POST Örneği

POST /api/v1/qr
Content-Type: application/json
{
  "token": "TOKENINIZ",
  "data": "https://ornek.com/menu",
  "color": "#0d6efd",
  "background": "#0b132b",
  "logo_url": "https://ornek.com/logo.png"
}

Logo eklemek için logo_url alanını kullanabilir veya base64 kodlu görsel için logo_upload alanını gönderebilirsiniz.

GET Örneği

https://qrmenu.noasoft.org/api/v1/qr?
  token=TOKENINIZ&
  data=https%3A%2F%2Fornek.com%2Fmenu&
  color=%230d6efd&
  background=%230b132b&
  embed=1

format=json veya output=json parametreleri eklendiğinde base64 çıktılı JSON yanıtı döner. Parametre olmadan direkt PNG çıktısı elde edebilirsiniz.

HTML İçerisinde Kullanım

<img
  src="https://qrmenu.noasoft.org/api/v1/qr?token=TOKENINIZ&data=https%3A%2F%2Fornek.com"
  alt="NoaSoft QR"
  width="280"
/>

Bu yöntemle sitenize gömdüğünüz her görüntü talebi paket limitinizden düşer. Renk, arka plan ve logo parametrelerini URL üzerinde eklemeye devam edebilirsiniz.

Başarılı Yanıt

{
  "status": "success",
  "image": "iVBORw0KGgo...",
  "mime": "image/png",
  "embed_url": "https://qrmenu.noasoft.org/api/v1/qr?token=TOKEN&data=..."
}

Dönen image alanı base64 kodlu PNG verisidir. Uygulamanızda data:image/png;base64, ön eki ile kullanabilirsiniz.

Hata Kodları

  • 400 - Parametre eksikliği veya hatalı istek
  • 401 - Token geçersiz, paket yok veya süresi doldu
  • 429 - Paket limitiniz doldu
  • 500 - QR oluşturma sırasında hata

Paket Limitleri

Her başarılı QR üretimi aboneliğinizin aktif paketinde tanımlanan limit ve sürelerden düşer. Paket süresi dolduğunda API erişimi otomatik olarak durur.

Tokenlarınızı müşteri panelinden pasif hâle getirebilir veya silebilirsiniz. Pasif tokenlar ile yapılan istekler reddedilir.
