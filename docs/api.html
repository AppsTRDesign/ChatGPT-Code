NoaSoft QR Menu API

JSON tabanlı token yapısı ile QR kod üretimini otomatikleştirin. Her istek aylık paket limitiniz kapsamında değerlendirilir.

Kimlik Doğrulama

Admin veya müşteri panelinde oluşturduğunuz tokenı Authorization: Bearer <TOKEN> başlığı ile veya JSON gövdesinde token alanında gönderin.

Endpoint

POST https://qrmenu.noasoft.org/api/qr.php

Örnek İstek

{
  "token": "TOKENINIZ",
  "data": "https://ornek.com/menu",
  "color": "#0d6efd",
  "background": "#0b132b",
  "logo_url": "https://ornek.com/logo.png"
}

Logo eklemek için logo_url alanını kullanabilir veya base64 kodlu görsel için logo_upload alanını gönderebilirsiniz.

Başarılı Yanıt

{
  "status": "success",
  "image": "iVBORw0KGgo...",
  "mime": "image/png"
}

Dönen image alanı base64 kodlu PNG verisidir. Uygulamanızda data:image/png;base64, ön eki ile kullanabilirsiniz.

Hata Kodları

  • 401 - Token geçersiz veya paket bulunamadı.
  • 429 - Aylık limit aşıldı.
  • 400 - Parametre eksikliği.

Paket Limitleri

Her başarılı QR üretimi aboneliğinizin aylık limitinden düşer. Admin panelinden paketlerinizi yükseltebilir veya banka havalesi ile ödeme bildirimi yapabilirsiniz.
