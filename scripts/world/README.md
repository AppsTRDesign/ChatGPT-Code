# World Data Builder

Node.js 16 uyumlu world bootstrap üretici scripti.

## Çalıştırma

```bash
node scripts/world/build-world-seed.js
```

## Üretilen dosyalar

- `backend/database/seeds/generated/002_world_bootstrap.sql`
- `backend/database/world-data/map-ready.json`

## Kaynak dosyalar

- `backend/database/world-data/countries.json`
- `backend/database/world-data/regions.json`
- `backend/database/world-data/cities.json`
